## 🔬 หลักการทำงาน
### Consistent Hashing
- แปลง `(c, s)` เป็นตำแหน่งบนแหวน 64 บิต
- แต่ละอาคารมีโหนดเสมือน `V` ตัว เพื่อกระจายโหลดสม่ำเสมอ
- เมื่อเพิ่ม/ลบอาคาร → ย้ายเฉพาะแขกส่วนที่เปลี่ยนเส้นทาง **ไม่กระทบทั้งระบบ**

### สูตรคำนวณหมายเลขห้อง
ใช้ **Cantor Pairing Function** ทำให้คู่ `(c, s)` ได้เลขห้องไม่ซ้ำกันเสมอ:
```
ห้อง = ((c-1)+(s-1)) × ((c-1)+(s-1)+1) ÷ 2 + (s-1) + 1
```

### สถิติที่คำนวณ
- **ค่าเฉลี่ย** = จำนวนแขก ÷ จำนวนอาคาร
- **ส่วนเบี่ยงเบนมาตรฐาน** — วัดการกระจายตัว
- **CV** (สัมประสิทธิ์การแปรผัน) = เบี่ยงเบน ÷ ค่าเฉลี่ย → ยิ่งน้อยยิ่งสมดุล

## 📝 หมายเหตุ
- รหัส `c` และ `s` ต้องเป็นจำนวนเต็มบวก ≥ 1 เสมอ
- ไม่สามารถลบอาคารที่เหลือเป็นอาคารสุดท้ายได้ (`N ≥ 1`)
- `common.py` ห้ามแก้สูตรคำนวณห้องและฟังก์ชันแฮช
